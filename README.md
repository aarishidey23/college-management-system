# 🎓 College Management System

A simple college event management website built using **HTML, CSS, and JavaScript**.

## ✨ Features

- 🏫 College homepage
- 💃 Dance competition registration
- 🎤 Singing competition registration
- 🎭 Drama competition registration
- 📅 Event dates and venues
- 📝 Student registration with name and ID number
- ✅ Registration confirmation message

## 🛠️ Technologies Used

- **HTML** – Website structure
- **CSS** – Styling and layout
- **JavaScript** – Registration interaction

## 🚀 How to Run

1. Clone or download this repository.
2. Open `College Management System.html` in your browser.
3. Select an event and click **Register**.
4. Enter your student name and ID number.
5. Click **Submit Registration** to see the confirmation.

## 📌 Note

This is a frontend project for educational purposes. Student registrations are not permanently stored in a database.
